> 用途：真实用户按本清单完成一次可绑定版本的试用，并回填 §6 回执——回执是
> `publish_ready` 的必要条件（D-03），代理/工程验收不能代填。
> 版本绑定：回执须注明所用工具链版本号与 SHA256（启动时 `--version`

## 1. 获取与启动（PowerShell）

前置：Windows x64；已安装与发布说明一致的 Node.js 与 pnpm；已获取冻结的工具链
（auto.exe）与源码（获取入口以 RELEASE.md「获取」节为准——本指南不预测 URL）。

```powershell
# 0) 建立独立的试用目录（与开发机路径无关的任意干净目录）
mkdir C:\jade-trial; cd C:\jade-trial

# 1) 放置冻结工具链（来源/hash 见 RELEASE.md），核对指纹
Get-FileHash -LiteralPath .\auto.exe -Algorithm SHA256   # 应与发布 checksums 一致
.\auto.exe --version

# 2) 获取 jade 源码（冻结版本）与兄弟仓依赖（结构见 RELEASE.md「获取」节）

# 3) 准备样例工作区副本（样例随源码交付：docs/releases/v0.1.0-rc/sample-workspace）
Copy-Item -Recurse <jade源码>\docs\releases\v0.1.0-rc\sample-workspace C:\jade-trial\my-wiki

# 4) 安装依赖并启动（两种形态任选；指南走查以原生 merged 为主形态）
$env:AUTO_EXE = "C:\jade-trial\auto.exe"
pnpm install
pnpm build
& $env:AUTO_EXE --version

# 形态一：原生 merged（主交付形态）
$env:JADE_WORKSPACE = "C:\jade-trial\my-wiki"
& $env:AUTO_EXE run -r vm

# 形态二：Vue 集成形（第二交付形态；后端 8211 / 前端 4443）
& $env:AUTO_EXE run -r vue --server vm -B 8211 -F 4443
#   浏览器打开 http://127.0.0.1:4443
```

注意：`-B/-F` 端口被占用时换空闲端口；`JADE_WORKSPACE` 指向**你的副本**，启动后
右侧状态行应显示 `workspace ready`。

## 2. 走查场景（原生 merged 主形态）

每项完成后在 §6 回执表勾选并记录实际观察。**异常按原样记录，不要跳过**——
安全拒绝/确认弹层是产品行为，不是故障。

### A. 基础写作闭环

| # | 步骤 | 期望 |
| --- | --- | --- |
| A1 | 启动后展开左侧 `wiki` 目录，打开「欢迎」 | 正文可见；状态栏无「未保存」 |
| A2 | 点击正文末尾，输入一行字 | 文字出现；状态栏出现「未保存」 |
| A3 | 点工具栏「保存」 | 「未保存」消失；底部注记出现 `saved: ...` |
| A4 | 关闭应用并重新启动，重新打开该页 | 刚才输入的行仍在 |
| A5 | 打开「空页」（0 字节） | 出现以页名为文本的标题行（输入起点） |
| A6 | 点击标题行，在标题后输入文字，回车换行再输入一段 | 输入正常；状态栏「未保存」出现 |
| A7 | 保存 → 重启 → 重新打开「空页」 | 标题与正文都在；文件不再为空 |
| A8 | 再打开任意页，把正文全部退格删掉（光标移到文末，长按 Backspace——注意：全选只作用于当前段落所在编辑宿主，删不完全文） | 删空后出现标题行输入起点（可再次输入） |
| A9 | 输入新内容并保存 → 重启读回 | 新内容在；旧内容已清空 |

### B. 保护与恢复

| # | 步骤 | 期望 |
| --- | --- | --- |
| B1 | 编辑一页不保存，直接点该页标签的关闭 | 弹确认：取消/放弃修改并关闭/保留草稿并关闭 |
| B2 | 选「取消」 | 编辑还在，未保存标记仍在 |
| B3 | 选「保留草稿并关闭」后重启，视图菜单开「待恢复草稿」 | 出现可恢复副本，恢复后内容回到 |
| B4 | 编辑另一页，不保存，点工具栏「重载」 | 弹「重载会放弃未保存修改」确认 |
| B5 | 退出应用（文件菜单退出），弹层出现时选「保存并退出」 | 保存后退出；重启读回 |
| B6 | 删除一页（右键或文件菜单「删除…」） | 确认弹层显示将影响的入链数；删除后可从回收站恢复 |

### C. 名称与导航

| # | 步骤 | 期望 |
| --- | --- | --- |
| C1 | `Ctrl+P`，输入「欢迎」 | 出现「欢迎」行（含别名 Start/首页 命中） |
| C2 | `Ctrl+P` 输入不存在的名字后按 Enter | 弹层留置、不建页不跳转；Esc 关闭 |
| C3 | 在正文输入 `[[写作示例]]`，保存后点击该链接 | 跳转到写作示例页 |
| C4 | 点击「欢迎」页中的悬空链接「尚不存在的页面」 | 弹建页确认；取消则不动磁盘 |
| C5 | 右栏开「反链」面板 | 显示引用当前页的来源页 |

## 3. 走查场景（Vue 集成形，第二形态）

启动形态二后重复 A1–A9、B1–B4、C1–C5 的核心项（A/B/C 全做更好）。额外注意：

- 浏览器内 `Ctrl+S`、工具栏、菜单三个保存入口都应真保存。
- 编辑器内不应看到任何「Save」按钮（旧版引擎动作栏已下线——若看到请截图回报）。
- 关闭方式：直接关浏览器标签即离开（后端仍在）；完全结束以后端进程终止为准。

## 4. 已知边界（如实告知，不算故障）

- 名称/全文匹配范围：页数 ≤200、名称匹配深度 8 层；超界有警示，属试用防线。
- 快捷键组合含 Shift 的部分（如 Ctrl+Shift+O/F/D）当前会被塌缩为不带 Shift 的行为
  ——请用菜单入口替代。
- 点击链接是保存后/已解析面；刚键入的 `[[链接]]` 文本不实时变链接样式。
- 原生窗内点开页不会自动把光标定位到目标锚点（开页≠定位）。
- 若空页/清空后无法输入（原生形态），请记录——这是本次试用重点核验项 E1。

## 5. 重点核验项 E1（原生空页键入）

A5–A7 即 E1：原生形态下空页是否可直接键入。若 A6 无法输入（点击标题行无光标、
键盘无响应），请记录：应用版本、步骤、现象截图。该项决定一条上游供给登记，
不影响其余结论。
